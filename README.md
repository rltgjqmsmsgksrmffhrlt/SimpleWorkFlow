# SimpleWorkFlow

오늘 하루 팀들의 목표와 과업, 협업을 한눈에 관리하는 실시간 워크플로우 보드입니다.

## 화면 구성

1. **대시보드** — 오늘의 궁극 목표를 크게 적고, 전체/팀별 진행률을 확인합니다.
2. **팀 보드** — 프론트엔드/백엔드/매니지먼트/디자인/네이티브/인프라/생성형AI/사이버보안 8개 팀이 각자 오늘 할 일을 시간순으로 등록합니다.
3. **협업 요청** — 다른 팀과 협업이 필요할 때 종을 울려 요청을 보내고, 회의 시간과 안건을 조율합니다.

모든 화면은 Socket.io를 통해 실시간으로 동기화되어, 같은 네트워크의 여러 사람이 동시에 접속해도 즉시 반영됩니다.

## 다른 사람에게 공유하기: SimpleWorkFlow.exe 하나만 전달

개발 환경(Node.js) 없이 다른 사람 PC에서 바로 켤 수 있는 실행 파일입니다. 더블클릭 한 번이면 서버 실행, 외부 공유 주소(Cloudflare 터널) 생성, 브라우저 열기까지 자동으로 됩니다. 창도 1개만 뜹니다.

**만드는 법 (개발자만, 최초 1회 또는 코드 변경 후)**
```bash
cd server
npm install
npm run package
```
`SimpleWorkFlow-dist/SimpleWorkFlow.exe` 파일이 만들어집니다. 이 파일 하나만 다른 사람에게 전달하면 됩니다(약 110MB).

**받은 사람이 쓰는 법**
- `SimpleWorkFlow.exe`를 더블클릭하면 검은 창이 하나 뜨고, 잠시 후 브라우저가 자동으로 열립니다.
- 같은 창에 외부 공유 주소가 출력됩니다 — 이 주소를 팀원들에게 보내면 인터넷 어디서든 접속할 수 있습니다.
- 데이터는 exe 파일과 같은 폴더에 `data.json`으로 저장됩니다.
- 끄려면 그 검은 창을 닫으면 됩니다.

### 주소를 고정하기 (권장, 무료)

기본 상태에서는 **켤 때마다 주소가 바뀌는** 임시 터널을 씁니다. 아래 3단계를 한 번만 하면 **항상 같은 주소**를 쓸 수 있습니다. 무료입니다.

1. **Microsoft Store**에서 `ngrok` 설치
   (공식 사이트에서 exe를 직접 받으면 Windows Defender가 오탐으로 삭제합니다. 반드시 Store 버전을 쓰세요.)
2. 발급받은 authtoken 등록 — PowerShell에서 한 번만 실행합니다:
   ```bash
   ngrok config add-authtoken 여기에_본인_토큰
   ```
   토큰은 https://dashboard.ngrok.com/get-started/your-authtoken 에서 확인합니다.
   (`$YOUR_AUTHTOKEN`을 그대로 붙여넣으면 PowerShell이 빈 값으로 바꿔버리니, 실제 토큰 문자열로 교체해야 합니다.)
3. exe를 한 번 실행하면 옆에 `ngrok-domain.txt`가 생깁니다. 그 파일 맨 아래에 본인의 무료 고정 도메인을 한 줄로 적습니다:
   ```
   lymphatolytic-suitably-derick.ngrok-free.dev
   ```
   도메인은 https://dashboard.ngrok.com/domains 의 목록에 이미 발급되어 있습니다 (`dev domain` 배지가 붙은 항목). 계정당 1개이며, 이름은 바꿀 수 없고 만료되지도 않습니다. "New Domain" 버튼으로 새로 만드는 것은 유료입니다.

이후로는 exe 더블클릭만 하면 항상 같은 주소로 뜹니다. 설정이 없거나 ngrok 실행에 실패하면 자동으로 임시 터널로 대체되므로, 잘못 설정해도 앱이 안 뜨는 일은 없습니다.

무료 플랜의 제약 두 가지:
- **월 1GB 전송량** — 이 앱은 번들이 gzip 약 75KB이고 알림음도 파일이 아니라 코드로 합성하므로, 30명이 한 달 내내 써도 여유롭습니다.
- **첫 접속 시 경고 페이지 1회 클릭** — 클릭하면 쿠키로 7일간 뜨지 않습니다.

### 여러 PM팀에 나눠줄 때

팀(조직)이 다르면 **데이터가 섞이면 안 되므로 조직마다 exe를 따로 돌립니다.**

- **한 조직 안에서는** 1명(팀장)만 exe를 켜고, 나머지 7개 팀은 그 주소로 접속합니다. 그래야 팀 간 협업 종이 서로 통합니다.
- **다른 PM팀에게는** exe를 건네주고, 그쪽 팀장이 위 "주소를 고정하기"를 각자 자기 ngrok 계정으로 설정합니다. 조직마다 독립된 `data.json`과 독립된 주소를 갖게 됩니다.

## 가장 빠른 실행 방법(개발용): start.bat 더블클릭

프로젝트 폴더의 `start.bat` 파일을 더블클릭하면 서버, 클라이언트, 외부 공유용 터널까지 창 3개가 자동으로 열립니다.

- 내 PC에서만 쓸 거면: 뜨는 창은 무시하고 `http://localhost:5173` 로 접속
- 외부(다른 네트워크) 사람과 같이 쓰려면: "Tunnel" 창에 표시되는 `https://....trycloudflare.com` 주소를 확인해서 공유
- 처음 실행하는 것이라면 `npm install`이 안 되어 있을 수 있으니, 아래 "실행 방법"을 따라 `server`, `client` 폴더에서 한 번씩 `npm install`을 먼저 해주세요. (한 번만 하면 됨)
- 끄려면 열린 3개의 검은 창(cmd)을 각각 닫으면 됩니다.

## 실행 방법 (수동으로, 또는 문제가 있을 때)

두 개의 터미널이 필요합니다.

**터미널 1 — 서버**
```bash
cd server
npm install
npm run dev
```
`http://localhost:4000` 에서 API/Socket 서버가 구동됩니다. 데이터는 `server/data.json` 에 저장됩니다.

**터미널 2 — 클라이언트**
```bash
cd client
npm install
npm run dev
```
`http://localhost:5173` 에서 화면을 확인할 수 있습니다.

## 다른 사람과 같이 쓰기 (같은 네트워크)

`npm run dev` 실행 시 터미널에 `Network: http://<이 PC의 IP>:5173/` 형태로 주소가 출력됩니다. 같은 Wi-Fi/네트워크에 있는 동료가 그 주소로 접속하면 동일한 화면을 실시간으로 공유합니다.

- 이 PC에서 서버와 클라이언트가 모두 켜져 있어야 합니다.
- Windows 방화벽에서 5173, 4000 포트에 대한 인바운드 연결을 허용해야 할 수 있습니다.
- 각자 접속 후 우측 상단에서 자신의 이름과 소속 팀을 선택하면, 협업 요청 알림이 자신의 팀 앞으로 온 것만 강조되어 보입니다.

## 다른 네트워크(다른 장소)에 있는 사람과 같이 쓰기

같은 Wi-Fi가 아니라 완전히 다른 곳(집, 카페, 다른 회사 등)에 있는 사람과 함께 쓰려면 인터넷에 공개되는 주소가 필요합니다. 가장 빠른 방법은 Cloudflare Tunnel(무료, 설치 불필요)로 임시 공개 URL을 만드는 것입니다.

**터미널 3 — 터널**
```bash
npx --yes cloudflared tunnel --url http://localhost:5173
```
실행하면 `https://무작위단어들.trycloudflare.com` 형태의 주소가 출력됩니다. 이 주소를 공유하면 어디서든 접속할 수 있습니다.

주의할 점:
- 이 터널은 **계정 없이 쓰는 임시 터널**이라 uptime 보장이 없고, `cloudflared` 명령을 껐다가 다시 켜면 **주소가 매번 바뀝니다**.
- 서버·클라이언트·터널 3개 프로세스가 모두 이 PC에서 켜져 있어야 접속됩니다. PC를 끄거나 잠자기 모드로 들어가면 끊깁니다.
- `client/vite.config.js`의 `server.allowedHosts`에 `.trycloudflare.com`을 이미 허용해뒀기 때문에 별도 설정 없이 바로 됩니다.
- 정식으로 팀이 상시로 쓸 주소가 필요하다면(껐다 켜도 주소 고정, PC를 안 켜둬도 접속 가능) Render/Railway 같은 곳에 서버+클라이언트를 배포하는 것을 추천합니다 — 필요하시면 말씀해주세요.

## 데이터 저장 및 날짜별 리셋

- 모든 데이터(목표/과업/협업 요청)는 서버가 실행 중인 컴퓨터의 `server/data.json` 파일에 저장됩니다.
- **대시보드의 목표**와 **팀 보드의 과업**은 매일 자동으로 리셋됩니다 — 날짜가 바뀌면 화면에는 오늘 등록된 것만 보이고, 어제 이전 것은 화면에서 사라집니다.
- 다만 완전히 삭제되는 것은 아니고, `server/data.json`에는 지난 기록이 날짜와 함께 계속 보관됩니다. (화면에서 지난 기록을 다시 조회하는 기능은 아직 없습니다.)
- 협업 요청도 목표/과업과 동일하게, 요청한 날짜가 지나면 화면에서 사라집니다. `data.json`에는 그대로 남아있습니다.
